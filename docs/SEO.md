## Данные, которые нужно получить у владельца

- Состав шиномонтажного комплекса, расходники, доплаты за RunFlat и низкий профиль.
- Модель стенда сход-развала, порядок проверки, наличие отчёта до/после.
- Состав компьютерной диагностики, оборудование, актуальная цена и продолжительность.
- Подтверждённые условия гарантии, опыт мастеров и сведения об организации.
- Три выполненных ремонта: автомобиль, жалоба, найденная причина, работы, результат, соответствующие фотографии. Стоимость и сроки — только если разрешено раскрывать.

По фотографиям нельзя приписывать автомобилю неисправность или выполненные работы.

## Подтверждение сайта

Если подтверждение выполняется HTML-метатегом, задать переменные окружения:

- `GOOGLE_SITE_VERIFICATION` — значение `content` метатега Google.
- `YANDEX_SITE_VERIFICATION` — значение `content` метатега Яндекса.

Это публичные коды подтверждения, не пароли и не OAuth-токены. После изменения переменных перезапустить локальный сервер или пересобрать опубликованный сайт. Для доменного ресурса Google Search Console используется DNS-подтверждение, а не HTML-метатег.

Добавление метатега само по себе не подтверждает сайт: проверку нужно завершить в соответствующем кабинете.

## После публикации

1. Проверить 200 для всех десяти страниц, canonical и доступность CSS, JavaScript и изображений.
2. Отправить `/sitemap.xml` в Google Search Console и Яндекс Вебмастер.
3. Проверить индексацию ключевых URL и регион сайта в Яндексе.
4. Сверить фактические адрес, телефон и часы работы на сайте и внешних карточках. Отдельно исправить старые упоминания дома 52, если это прежний адрес.
5. Проверить поступление целей Метрики: `phone_click`, `route_click`, `reviews_click`, `price_source_click`, `vk_click`. Сами цели нужно создать или проверить в кабинете Метрики.

## Как выбирать следующие задачи

Еженедельно сравнивать поисковые показы, клики и обращения по каждой странице. Учитывать сезонность и брендовые запросы отдельно.

- Нет индексации: проверить доступность, canonical и отчёт поисковика.
- Есть показы, мало переходов: проверить соответствие title, описания и содержания реальному запросу.
- Есть переходы, мало обращений: проверить понятность цены, состава работ и записи.
- Есть спрос на услугу без отдельной страницы: подготовить её по подтверждённым сведениям.

Не обещать топ или конкретный прирост без статистики. Не создавать одинаковые страницы под соседние населённые пункты без самостоятельной пользы для посетителя.
