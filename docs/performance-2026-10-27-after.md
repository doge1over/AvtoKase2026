## Изменения

- Подмножества шрифтов: 478 040 → 168 936 байт (−64,7%). Сохранены обычная латиница, кириллица, цены, стрелки, пунктуация и дополнительные символы текущих исходников. Сохранён исходный диапазон вариативных начертаний. Проверены наличие глифов и ширина контрольной строки на используемых весах с допуском 0,05%.
- В галерее сначала восемь превью, затем кнопка «Показать ещё». Все 24 оригинала доступны при открытии снимков.
- Первые два превью загружаются с приоритетом; остальные лениво. Уточнены размеры превью под реальную сетку, добавлены промежуточные размеры 320/384/480/512 px и качество 65 для превью. Качество полноразмерного просмотра сохранено.
- Подключён sharp 0.34.5 для обработки изображений Next.js, совместимый с Node.js 18.17+/20.3+.
- Все 24 оригинала галереи перечислены в image sitemap для обнаружения поисковиками.

## Проверки

- Производственная сборка npm run build прошла.
- npm run optimize:fonts воспроизводит файлы из исходных TTF, проверяет глифы и метрики.
- Chrome, экран 390 px: шрифты загружаются, ошибок гидратации и горизонтального скролла нет.
- Галерея: 8 → 16 → 24; последняя фотография открывается и закрывается.
- Цели телефона, маршрута, отзывов и прайса продолжают отправляться.
- В image sitemap 24 изображения, всего страниц в sitemap — 10.

## Условия и ограничения

Та же версия Lighthouse 13.5.0, тот же Chrome и локальный адрес http://localhost:3000, производственная сборка. Мобильный профиль: симуляция сети 1638.4 Кбит/с, RTT 150 мс, CPU ×4. Последовательные запуски с обычным сбросом хранилищ Lighthouse. Серверный кэш изображений не сбрасывался принудительно; состояние кэша может влиять на отдельные прогоны.

Это лабораторные показатели, не реальные пользовательские Core Web Vitals и не гарантия того же результата на хостинге. LCP главной и услуги в мобильной симуляции ещё выше целевого ориентира 2,5 с, несмотря на высокий общий балл. INP не измерялся.
