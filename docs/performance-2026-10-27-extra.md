# Дополнительное ускорение — 27 октября 2026

## Итоговый код

- Шрифты: 168 936 → 88 816 байт, уменьшение на 47,4%. Сохранены весь русский алфавит, ASCII, неразрывные пробелы, денежные символы и дополнительные символы исходников app/. Стандартное формообразование и кернинг сохранены, неиспользуемые стилистические наборы удалены.
- Генератор npm run optimize:fonts проверяет наличие глифов, диапазоны вариативных начертаний и ширину контрольной строки с допуском 0,05%. Для новых символов вне базовых диапазонов повторить генерацию.
- Для карточек услуг и кнопки галереи на главной, а также верхних хлебных крошек услуг отключена автоматическая предзагрузка соседних страниц. Навигация по нажатию сохранена.
- В галерее высокий приоритет только у первой фотографии; все 24 фотографии доступны через «Показать ещё».
- Исходная загрузка Метрики и обеих гарнитур оставлена: эксперимент с их задержкой выигрыша не дал.

## Контроль галереи с прямым ограничением сети

Lighthouse --throttling-method=devtools, одинаковая текущая страница через два локальных прокси. Один отдаёт прежние шрифты 168 936 байт, другой — итоговые 88 816 байт. Остальной код и сервер одинаковы. По одному прогону на вариант: это контроль влияния шрифтов, а не полевые данные пользователей и не полный повтор прежней версии.

| Вариант | Performance | FCP, с | LCP, с | Передано, КиБ |
| --- | ---: | ---: | ---: | ---: |
| Прежние шрифты | 99 | 1.42 | 1.43 | 557 |
| Компактные шрифты | 99 | 1.43 | 1.45 | 480 |

Разница LCP около 13 мс в одном A/B-прогоне не даёт основания считать один вариант быстрее другого. Объём загрузки уменьшился примерно на 79 КБ. Этот контроль не подтвердил заметного ухудшения от компактных шрифтов, но для строгого сравнения галереи нужна серия прямых замеров или реальные пользовательские данные.

## Проверки и условия

Производственная сборка прошла. Chrome: 390 px, шрифты загружаются, гидратация без ошибок, нет горизонтального скролла. Галерея раскрывается 8 → 16 → 24, последний снимок открывается и закрывается. Переход с главной по карточке шиномонтажа работает без prefetch. Цели телефона, маршрута, отзывов и прайса отправляются.

Стандартные прогоны: Lighthouse 13.5.0, локальный next start, сеть 1638.4 Кбит/с, RTT 150 мс, CPU ×4. Прогоны последовательные. Серверный кэш изображений не очищался. INP и полевые Core Web Vitals не измерялись. Хостинг может дать другие результаты.
